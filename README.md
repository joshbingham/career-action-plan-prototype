# Career Action Plan Prototype

Frontend prototype for a careers adviser workflow setup screen.

## Overview

This project was built as part of a paid frontend practical task focused on:
- template selection
- session setup
- form validation
- conditional interaction flow

The implementation intentionally focuses on simplicity, usability and clean frontend structure in line with the project brief.

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Features

- Template selection interface
- Conditional session setup form
- Required field validation
- Disabled/enabled continue state
- Responsive layout
- Confirmation state on completion
